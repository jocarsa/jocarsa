## Sobre mí

Soy desarrollador de software y docente especializado en **programación, sistemas y automatización**, con una fuerte orientación a la **educación técnica**, el **desarrollo de herramientas empresariales** y la **aplicación práctica de la inteligencia artificial**.

Combino la **ingeniería de software tradicional** (backend, bases de datos, sistemas) con **IA aplicada**, automatización de procesos y creación de **ecosistemas educativos digitales**, tanto para uso académico como profesional.

Trabajo con un enfoque muy claro: **entender el problema real, diseñar soluciones sólidas y mantener el control total del sistema** (código, datos, infraestructura).
